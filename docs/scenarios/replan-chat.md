# /replan チャット対話・予定変更のテストシナリオ

## 1. 突発的な予定割り込み・遅延
- [ ] **急な予定の挿入**
  - 入力: 「急に友達から飲み会に誘われた（19:00〜21:00）」
  - 期待する挙動: 19:00〜21:00にあった既存タスクを前後にずらすか別日に移動し、飲み会を予定としてセットする。
- [ ] **即時開始の予定追加（今から〜したい）**
  - 入力: 「今から30分プログラミング勉強したい」「今すぐ散歩に行きたい」
  - 期待する挙動: 現在時刻から即座に指定タスクを割り込ませ、直後に控えていた既存予定を後ろ倒し・再構成する。
- [ ] **現在進行形の遅延**
  - 入力: 「電車が30分遅れてる」「今の作業が1時間長引きそう」
  - 期待する挙動: 現在時刻以降の全予定を30分〜1時間後ろ倒しにし、溢れた分を適切に処理する。

## 2. 体調・感情・生理的状態への対応
- [ ] **「眠い」への対応（仮眠提案）**
  - 入力: 「めちゃくちゃ眠い」「頭が回らない」
  - 期待する挙動: 15〜20分程度の仮眠時間（パワーナップ）の挿入を提案し、仮眠後の予定を後ろ倒し・削減する選択肢を提示する。
- [ ] **抽象的なモチベーション低下・感情**
  - 入力: 「今日なんかやる気出ない」「全部めんどくさい」
  - 期待する挙動: AI側から具体的な提案（例: 「優先度の低いAタスクを明日に回して、今日の作業時間を半減させますか？」）の選択肢を出す。

## 3. 条件付き・不可能な要求への対応
- [ ] **物理的に不可能な変更要求（譲歩案の提示）**
  - 入力: 「残り2時間で、残りのタスク（計5時間分）を全部終わらせるように組んで」
  - 期待する挙動: 「不可能です」と拒否するだけでなく、最優先タスクのみを残したり、作業時間を限界まで短縮する等の『実行可能な最大限の譲歩案』を提示する。
- [ ] **タスクの入れ替え・前倒し**
  - 入力: 「Aのタスクは気が乗らないからBからやりたい」「明日のタスクを今日やりたい」
  - 期待する挙動: 順序の入れ替えや明日のタスクの前倒しを行い、時間枠を超過しないか計算して配置する。

## 4. 目標時間・制約に関する注意・警告
- [ ] **週目標時間の未達成リスク警告**
  - 入力: 「今日のプログラミング学習（2時間）をキャンセルして自由にしたい」
  - 期待する挙動: 変更によって今週の目標時間（例: 週10時間）に届かなくなる場合、確定前に「この変更を行うと今週の目標時間に2時間届かなくなります。確定しますか？」等の注意・警告メッセージを提示する。

## 5. 文脈維持・前言撤回
- [ ] **直前の変更のキャンセル**
  - 入力: 「やっぱりさっきの提案ナシで、元のスケジュールに戻して」
  - 期待する挙動: 直前の会話による変更を取り消し、変更前の状態に戻す。
- [ ] **複数案の選択**
  - 入力: AIが「案1：タスク削減」「案2：明日へ繰り越し」を出した後に「案2でお願い」と返答
  - 期待する挙動: 案2の内容を正確に反映したスケジュールデータを作成する。
